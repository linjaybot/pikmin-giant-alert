# 🍄 피크민 블룸 거대버섯 자동 참가봇 (v5.1)

> **v5.1 (2026-09-13) 중요 업데이트 — v5를 받으셨다면 이 버전으로 교체하세요.**
> v5에는 거대버섯을 놓치는 버그가 있었습니다. 실측으로 확인된 내용:
> - 참가 화면에서 GO(전송) 버튼을 누르기까지 **약 50초**가 걸렸습니다(매번 AI 비전 호출로 좌표를 찾다가 4번 재시도). v5.1은 화면 글자 인식으로 바로 찾아 **1~2초**에 누릅니다. 사람 많은 시간대엔 이 차이로 무조건 놓칩니다.
> - 같은 버섯인데 카드 장소명이 말줄임으로 잘려 읽히면 다른 버섯으로 취급돼, 멀쩡한 거대를 **3시간 넘게 무시**한 사례가 있었습니다.
> - 봇을 켜는 순간 화면에 떠 있던 거대 카드를 "이미 아는 것"으로 등록해 **영구히 무시**했습니다. 이제는 실제로 들어가 보고 본인이 이미 참가한 경우(참가자 목록에 "당신")만 조용히 넘어갑니다.
> - 카드 발견 시 연속 2프레임 확인을 기다리던 6초를 없앴습니다.


거대버섯 뜨고 1분이면 자리 꽉 차서 맨날 놓치는 사람을 위한 도구.

아이폰 화면을 맥에 미러링해두면, 맥이 6초마다 피크민 맵을 지켜보다가
**거대버섯이 새로 나타나는 순간 봇이 알아서 카드를 탭 → 참가 → 피크민 자동 전송까지 끝내준다.**
실패했을 때만 팝업+알람으로 사람을 부른다. 미러링이 끊기면 그것도 알아서 복구를 시도한다.

## 이 버전이 하는 일 (2026-07 초기 버전과 다른 점)

- **거대버섯 자동 참가**: 새 거대 발견 → 카드 탭 → 참가 → 피크민 자동 선택 → 확정까지 봇이 직접 화면을 터치해서 끝낸다. 실패할 때만 알림으로 폴백.
- **생김새가 매달 바뀌어도 감지**: 이미지 템플릿(`templates/*.png`)으로 1차 검출하고, 모르는 모양이면 Claude(`claude -p` 비전)가 최종 판정한다.
- **미러링 자동 복구**: 아이폰 미러링이 끊기거나 멈추면(전화 옴, 화면 잠김, 앱이 꺼짐 등) 이것도 감시해서 자동으로 재연결·재실행을 시도한다.
- **상단바 인디케이터**: 메뉴바에 지금 상태(감시 중 / 맵 아님 / 미러링 없음 / 알림 중 등)가 뜨고, 화면 위에 항상 떠 있는 작은 상태 위젯도 켤 수 있다.
- **하루 도전 횟수 인식**: "오늘은 앞으로 N회" 표시를 읽어서, 0회가 되면 그날 자정까지 조용히 있다가 다음날 자동으로 재개한다.
- **지도 영점조준 자동화**: 감시를 시작하면 지도가 축소된 넓은 뷰로 남아있을 수 있는데(마커가 몰려 보이는 원인), 시작 직후 봇이 알아서 첫 버섯 카드를 한 번 탭→뒤로가기 해서 지도를 그 동네로 맞춰준다.

## 준비물

- **맥** (macOS Sequoia 15 이상 — iPhone 미러링 기능 필요). Apple Silicon 기준으로 만들었음(인텔맥이면 아래 "커스터마이징" 참고)
- **아이폰** (맥과 같은 Apple 계정, 미러링 가능해야 함)
- **Python 3** (맥 기본 포함, Xcode Command Line Tools의 `/usr/bin/python3`로 테스트함)
- **[Claude Code](https://claude.com/claude-code) 설치 + 로그인 (Pro/Max 구독 또는 API 키)** — 이 봇은 거대버섯 생김새 판정, 참가 버튼 찾기, 미러링 복구 판단에 `claude -p` (Claude Code CLI)를 백그라운드에서 호출한다. **구독 로그인이 안 돼 있으면 봇이 애매한 상황에서 판단을 못 한다.**
- **Homebrew + cliclick** (`brew install cliclick`) — 화면 클릭 자동화용
- 피크민 블룸 설치된 폰, 게임 언어는 **한국어**로 (아래 "다른 언어 쓰면?" 참고)

## 설치

### 제일 쉬운 방법 — 클로드한테 맡기기

Claude Code가 있으면 이 폴더를 아무 데나 두고 이렇게 말하면 끝:

```
이 폴더(pikmin-giant-alert)는 피크민 블룸 거대버섯 자동참가봇이야.
README를 읽고 세팅해줘. 필요한 파이썬 패키지·brew 패키지 설치하고,
화면 기록/손쉬운 사용 권한 안내까지 포함해서 실행 방법 알려줘.
```

### 수동 설치

1. 홈에 받기. **git으로 받아두면 나중에 업데이트가 한 줄로 끝나니 이 방법을 권장**:
   ```bash
   git clone https://github.com/linjaybot/pikmin-giant-alert.git ~/pikmin-watch
   chmod +x ~/pikmin-watch/start.sh
   ```
   git이 없거나 쓰기 싫으면 이 페이지 우측 상단 **Code → Download ZIP** 으로 받아서 압축을 풀고,
   폴더 이름을 `pikmin-watch`로 바꿔 홈(`~`)에 두면 됩니다. (단, 업데이트 때마다 다시 받아야 합니다)
2. 파이썬 패키지 설치:
   ```bash
   pip3 install opencv-python-headless numpy \
     pyobjc-framework-Quartz pyobjc-framework-Vision pyobjc-framework-Cocoa rumps
   ```
3. cliclick 설치:
   ```bash
   brew install cliclick
   which cliclick   # /opt/homebrew/bin/cliclick 이 아니면 아래 "커스터마이징" 참고
   ```
4. Claude Code 설치 + 로그인 (이미 쓰고 있다면 생략):
   ```bash
   claude --version   # 확인
   which claude       # 이 경로가 ~/.local/bin/claude 가 아니면 아래 "커스터마이징" 참고
   ```
5. **화면 기록 + 손쉬운 사용 권한**: 시스템 설정 → 개인정보 보호 및 보안 → **화면 기록** / **손쉬운 사용** → 터미널(또는 사용하는 터미널 앱) 허용.
   (창 캡처 + 자동 클릭 둘 다 필요. 처음 실행하면 권한 요청 팝업이 뜬다. 허용 후 터미널 앱을 껐다 켜야 반영되는 경우가 있음)

## 업데이트 (중요)

아직 실전에서 다듬고 있는 도구라 고칠 일이 계속 생깁니다. **가끔 업데이트를 받아주세요.**

```bash
cd ~/pikmin-watch
git pull
피크민            # 또는 ~/pikmin-watch/start.sh — 새 코드로 재시작
```

`git pull` 후에는 봇을 반드시 다시 실행해야 새 코드가 적용됩니다(파이썬은 실행 중 코드를 다시 읽지 않음).
개인 설정(`state.json`, 로그 등)은 `.gitignore`에 있어서 업데이트로 날아가지 않습니다.
ZIP으로 받으셨다면 새로 다운로드해서 `.py` 파일들만 덮어쓰면 됩니다.

버전은 `pikmin_watch.py` 맨 위 주석에 날짜로 적혀 있고, 무엇이 바뀌었는지도 거기 있습니다.

## 사용법

1. 아이폰을 충전기에 꽂아두고, 맥에서 **iPhone 미러링** 앱 실행
2. 미러링 안에서 피크민 블룸 열고 **탐험 탭**(맵 + 하단 버섯 리스트 보이는 화면) 띄워두기
3. 터미널에서:
   ```bash
   ~/pikmin-watch/start.sh
   ```
   → 감시봇 + 상단바 + 미러링 복구 데몬 3개가 백그라운드로 뜬다.
4. 편하게 쓰려면 `~/.zshrc`에 alias 추가 (터미널 재시작 또는 `source ~/.zshrc` 필요):
   ```bash
   alias 피크민='~/pikmin-watch/start.sh'
   ```
   그 다음부턴 그냥 `피크민` 입력.
5. 종료는 **메뉴바의 🍄 아이콘 클릭 → "모두 종료"**, 또는 터미널에서:
   ```bash
   pkill -f pikmin_watch.py; pkill -f pikmin_menubar.py; pkill -f mirror_recover.py
   ```
6. 재부팅하면 자동으로 안 켜짐 — 다시 켜려면 `피크민` 한 번 더 실행.

**기본값은 토요일 00:00 ~ 월요일 00:00(한국시간)만 감시한다** (평일엔 화면이 떠 있어도 안 봄). 바꾸려면 아래 "커스터마이징" 참고.

## ⚠️ 반드시 알아야 할 것

- **봇이 실제로 참가 버튼을 눌러서 피크민을 자동으로 보낸다.** 하루 도전 횟수(보통 2~3회)를 사람 확인 없이 소모한다. 원치 않으면 `pikmin_watch.py` 상단의 `AUTO_JOIN = True`를 `False`로 바꾸면 감지만 하고 알림으로만 알려준다(참가는 안 함).
- **폰을 들고 나가면 봇을 꺼라.** 미러링 화면이 움직이면 헛알림·오작동 원인. 폰 거치 상태(충전 중) 전용으로 설계됨.
- **게임 API를 안 건드리고 화면만 본다** — 계정 정지 등 서버 쪽 위험은 없음. 다만 클릭 자동화이므로 화면 레이아웃이 바뀌면(피크민 블룸 업데이트 등) 오작동할 수 있음.
- **`claude -p` 호출은 항상이 아니라 애매할 때만** (새 모양 거대 판정, 미러링 복구 판단 등) 일어난다 — 평소엔 이미지 매칭만으로 처리해서 호출이 잦지 않음. 그래도 Claude 구독 사용량에 포함되니 참고.
- **거대버섯 생김새는 매달 이벤트마다 바뀐다.** `templates/`에 있는 두 장(`giant_blue.png`, `giant_mystery.png`)은 지금 이벤트 기준. 템플릿에 없는 새 모양은 Claude 비전 판정이 커버하지만, 정확도를 높이고 싶으면 미러링 화면을 캡처해서 새 거대버섯의 갓 부분만 잘라 `templates/`에 png로 추가하면 됨(여러 장 있어도 다 검사함). Claude한테 "새 거대버섯 스샷 줄게, 템플릿 갈아줘" 하면 알아서 해줌.
- 감지 순간 스크린샷은 `~/pikmin-watch/hits/`·`joins/`에, 로그는 `watch.log`·`recover.log`에 쌓임 — 실제 동네 지도가 찍히니 남한테 공유할 땐 이 폴더들은 빼고 보낼 것(이 배포판엔 처음부터 안 들어있음).

## 커스터마이징 포인트 (`pikmin_watch.py` 상단 상수)

| 상수 | 기본값 | 의미 |
|---|---|---|
| `ACTIVE_WEEKDAYS` | `(5, 6)` (토, 일) | 감시 요일. 매일 돌리려면 `(0,1,2,3,4,5,6)` |
| `AUTO_JOIN` | `True` | 자동 참가 여부. `False`면 알림만 |
| `CLAUDE_CLI` | `~/.local/bin/claude` | Claude Code 실행 경로. `which claude` 결과가 다르면 이 값을 바꿀 것 |
| `CLICLICK` | `/opt/homebrew/bin/cliclick` | Apple Silicon 기본 경로. **인텔맥이면 보통 `/usr/local/bin/cliclick`** — `which cliclick`으로 확인 후 수정 |
| `INTERVAL_SEC` | `6` | 화면 감시 주기(초) |

## 다른 언어 쓰면?

macOS/피크민 블룸이 한국어가 아니면 OCR·트리거 문구가 안 맞는다. `pikmin_watch.py` 상단의 `MAP_MARKERS`("탐험","모종","엽서","라이프"), `INVITE_WORDS`("초대"), `JOIN_BUTTON_TEXTS`("참가" 등), `DISCONNECT_WORDS` 등을 그 언어 표현으로 바꿔야 함. 이것도 Claude한테 "게임 언어를 영어로 바꿨어, 문구들 영어로 맞춰줘" 하면 해줌.

## 잘 안 될 때

- **상단바에 "미러링 창 없음"만 반복** → iPhone 미러링 앱이 실제로 켜져 있는지, 창이 최소화돼 있지 않은지 확인. `mirror_recover.py`가 자동으로 살리려고 시도는 함.
- **캡처/클릭이 전혀 안 먹음** → 화면 기록·손쉬운 사용 권한 확인 (설치 5번). 권한 준 뒤 터미널 앱을 완전히 재시작해야 반영될 때가 있음.
- **"맵 화면이 아님"만 뜸** → 폰에서 피크민 블룸의 **탐험 탭**(하단 버섯 리스트 보이는 화면)을 띄워뒀는지 확인.
- **자동 참가가 이상한 타이밍에 눌림 / 이미 꽉 찬 방에 들어감** → 서버 쪽 방 정원과 화면 표시 사이에 시차가 있어서 가끔 발생할 수 있음. 잦으면 `AUTO_JOIN = False`로 바꿔서 알림만 받고 직접 참가하는 걸 권장.
- **한글 인식이 이상함** → 위 "다른 언어 쓰면?" 참고.
